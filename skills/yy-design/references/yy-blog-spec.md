## 2. 文章页布局

- **Header**：占顶 30vh，左侧 `{翊}` logo + 文章标题，右侧大留白
- **正文宽度**：680px 居中（最大宽，超过两端留白）
- **行高**：1.8 · **段落间距**：1.5em
- **图片**：默认满正文宽，自带 1px 细灰边框 `#E5E5E5`
- **代码块**：深色主题（底 `#0A0A0A`、字 `#FAFAFA`、关键字终端绿）+ JetBrains Mono 14px
- **引用块**：左侧终端绿竖线 4px + 背景 5% 灰 + 字体倾斜
- **TOC（目录）**：右侧浮动，灰色小字，当前项终端绿

## 4. wangyiyang.cc 现状盘点与改造方案

> **现状快照**（2026-05-31 抓取自 `wangyiyang.cc`）：首页大标题为「王翊仰的技术笔记」，副标「记录代码、AI 和工程实践中的思考与踩坑。」；内容分三区 🔥 本周最热 / 📈 持续热门 / 🆕 最新发布，文章以「标题 + 摘要（部分带日期 / 分类标签）」列表呈现。整体仍是「通用技术博客」气质，尚未套用翊行代码 VI。

### 4.1 差距盘点（现状 → VI 目标）

| 维度 | 现状 | VI 目标 | 改造动作 |
| --- | --- | --- | --- |
| 品牌出场 | H1「王翊仰的技术笔记」，无 Logo | `{翊}` Logo + 主品牌名「翊行代码」 | 顶部换 `{翊}` Logo + 翊行代码；「王翊仰的技术笔记」降为副标 / 站点描述 |
| Tagline | 仅「记录代码…踩坑。」 | 英文 tagline「Code, one stroke at a time.」 | 首屏加英文 tagline；原句保留为口语化副描述 |
| 配色 | 偏默认浅色，待核实 | 冷白 `#FAFAFA` / 碳黑 `#0A0A0A` / 终端绿 `#00E676` | 背景冷白、正文碳黑、链接与强调终端绿，严守三色不另立新色 |
| 分区图标 | 彩色 emoji 🔥📈🆕 | 简单 + 神秘、抽象优先、碳黑 + 一点终端绿 | 去彩色 emoji，改终端绿细线 + 思源黑小标题或极简文字标签 |
| 字体 | 待核实 | 标题与正文思源黑 / 代码 JetBrains Mono | 统一接入无衬线字体栈，以字重建立层级 |
| 文章卡片 | 样式不统一 | 1px 细灰边框 `#E5E5E5`  • hover 终端绿 | 统一卡片：细灰边框、标题思源黑 Bold、hover 终端绿 |
| Favicon / Footer | 缺 `{翊}` 元素 | 极简 `{翊}` favicon + 终端绿单色版 footer | 补 favicon 与 footer 印章（见 §1 / §6.3） |

### 4.2 分阶段改造

- **P0 · 品牌一致性（先做）**：顶部 `{翊}` Logo + 翊行代码、英文 tagline、三色配色、字体栈、去掉彩色 emoji 分区图标。
- **P1 · 页面体验**：文章页布局套 §2、代码块深色主题 + JetBrains Mono + 终端绿关键字、OG 自动出图套 §3。
- **P2 · 仪式感**：footer 终端绿单色版 `{翊}`、首屏 / 文章头图引入「双重空间 + 极简静物」或咖啡静物 hero（套 AI 生图 Prompt Kit §4.6.B），哑光纸面咖啡渍纹理点缀。
