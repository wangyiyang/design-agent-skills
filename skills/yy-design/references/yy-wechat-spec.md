## 1. 文章结构模板（从上到下）

1. **封面图**（1.91:1，含 `{翊}` 角标 + 主题图 + 标题 + 品牌名）
2. **正文标题**（思源黑体 Bold，碳黑）
3. **副标题或引语**（思源黑体 Regular，碳黑 60%）
4. **正文**（思源黑体 Regular，碳黑，行高 1.8，段间空一行）
5. **小标题**（思源黑体 SemiBold，前缀终端绿 ▌ 或方块）
6. **引用块**（左侧终端绿 4px 竖线，背景 5% 灰，字体倾斜）
7. **代码块**（碳黑底 + 冷白字 + JetBrains Mono + 关键字终端绿）
8. **配图**（4:3 或 1:1，居中，下方灰色 Caption 12px）
9. **文末签**（固定写法见 §3）
10. **作者卡**（`{翊}` logo + 简介 + 联系方式）

## 2. 封面图规范

- 比例 **1.91:1**（公众号兼容）
- 主视觉占左 60%，文字占右 40%
- 必含：`{翊}` logo 角标（缩小尺寸）+ 主题图 + 主标题 + 「翊行代码」品牌名
- 字号：主标题 64px / 副标题 32px / 品牌名 24px
- Prompt 套用 **AI 生图 Prompt Kit** §4.3 OG Image **或 §4.6.B 双重空间 + 极简静物 hero（YY 偏好，气质更强）**，在右下角加 `{翊}` 角标
- 命名：`yy-wechat-cover-{主题}-{yymmdd}.png`

## 3. 文末签固定写法

```text
━━━━━━━━━━━━━━━━━━━━
[{翊} 终端绿单色版 · 60×60px]

翊行代码 · YY
Code, one stroke at a time.

▸ 博客：wangyiyang.cc
▸ GitHub：github.com/wangyiyang
▸ 商务合作：[邮箱]
━━━━━━━━━━━━━━━━━━━━
```

## 4. 正文排版铁律

- ✅ 段落之间空一行（视觉呼吸）
- ✅ 关键句加粗，**一篇最多 3 处**
- ✅ 关键词终端绿，**一篇最多 5 处**（绿是信号不是装饰）
- ✅ 列表项前用 ▸ 或 · 而不是默认 - / \*（更精致）
- ❌ 不用全屏 emoji 装饰、动图、闪烁元素
- ❌ 不用渐变色字体、阴影字、艺术字
