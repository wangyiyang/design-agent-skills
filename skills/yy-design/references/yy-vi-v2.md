## 适用范围

仅在产出代表「翊行代码」、YY、王翊仰或 `wangyiyang.cc` 时强制应用本规范。为其他客户或品牌工作时，使用对方的品牌资产，不套用本 VI。

## Brand DNA

- 简单 + 神秘：表面极简，内里藏结构。
- 匠人之气：匠心、克制、严谨、务实节用，不借古典符号。
- 静水深流：像精密仪器待机，安静但通着电。
- 咖啡仪式感：可用“一壶一杯”等极简静物表达专注节奏，不引入咖啡棕。
- 抽象优先，暗示优于描述；工业极简、精密器物、高级产品摄影。

## 品牌名 × 主视觉的连接

三层连接，不牵强附会：

- **音 · 翊行（yì háng）≈ 一行（yī háng）** → 翊行代码 ↔ **一行代码 · 1 line code**。这是品牌名最直接、最独有的一层。
- **码 · `{ }`** → 代码块边界，直接说明技术语境。
- **状态 · 终端绿点** → 系统在线、任务运行、能量被精确控制；安静，但通着电。

`{翊}` 是「翊行代码」的紧凑标识：**花括号 = 代码，「翊」= 名字，绿点 = 在线状态**。不再把「翊」强行解释成一笔书法，也不要求字形一笔写成。

英文 tagline `Code, one stroke at a time.` 表达的是**一次推进一个动作、逐步构建系统**的方法论，不是 Logo 的造型命令。视觉可以呼应“连续推进”，但不得为了 tagline 扭曲汉字结构。

**短描述（用于 bio / OG 副标 / GitHub README 首行）**：`翊行代码 · 1 line code` 或 `翊行代码（yì háng dài mǎ）≈ 一行代码`。不起 tagline 作用，只在需要解释品牌名时使用。

## 字体系统

| 内容 | 字体 | 字重 |
| --- | --- | --- |
| 中文标题 | Source Han Sans SC / Noto Sans CJK SC | 700 |
| 中文正文 | Source Han Sans SC / Noto Sans CJK SC | 400 / 500 |
| 英文 | Inter | 400 / 600 |
| 代码 | JetBrains Mono | 400 |

中文标题与正文都使用无衬线字体，以字重、字距和比例建立层级。禁止宋体、书法、手写和复古字体。

**字号阶梯（参考）**：H1 32 · H2 24 · H3 20 · 正文 16 · 小字 14 · Caption 12（单位 px）

**行高**：标题 1.3 · 正文 1.7 · 代码 1.5

**禁用字体**：微软雅黑、Arial、Times New Roman、系统宋体、华文行楷、艺术字——业余气，与品牌相斥。

## `{翊}` 几何字标

v2.1 Logo 尚待正式矢量重绘。不要使用或换色复用 v1.x 手写 SVG，也不要临时伪造“官方 Logo”。需要 Logo 时，向用户索取新的 v2.1 资产；没有资产时使用带说明的几何占位符。

正式结构要求：

- 24×24 网格重构可辨识的「立 + 羽」，统一线宽、平切端点、小圆角。
- 左右花括号严格镜像，并与字形共享线宽和圆角。
- 右括号内右下放字高约 7% 的终端绿方形状态灯，无渐变、透明或光晕。
- 字形、内部留白、括号比例约为 `1 : 0.28 : 0.16`。
- Logo 四周安全间距至少为「翊」字高度 50%；屏幕最小宽度 32px。
- 禁止拉伸、旋转、改色、描边、阴影、立体化、外发光和叠加文字。

重绘要点：

- **先验证小尺寸**：先验证 16 / 24 / 32 px，再完善 256 / 2048 px；小尺寸允许删减内部短线，但不得改变识别骨架。
- **构图**：花括号高度约字高 1.12 倍；字与括号间距约字宽 28%；整体光学居中。
- **只交付符号**：英文 tagline 与中文品牌名属于独立 wordmark / 排版系统，不嵌入 Logo。
- **交付物**：`yixing-logo-v2-master.svg`、`yixing-logo-v2-mono-black.svg`、`yixing-logo-v2-mono-white.svg`、`yixing-logo-v2-favicon-32.png` + `favicon-16.png`、`yixing-logo-v2-construction.pdf`、`yixing-logo-v2-usage.pdf`。

## Hero：对峙与张力

Hero 使用“明暗对峙 + 一点终端绿张力 + 大量留白”，可选一个极简实物锚点。

- 对峙方向可以是左右、上下、对角或包围。
- 张力形态可以是细线、点、痕、裂隙或短笔触。
- 锚点只选一组咖啡器物、金属工具或电子器物，也可完全抽象。
- 留白至少 60%；画面只保留一个视觉焦点。
- 连续交付不可复用同一构图配方。

- 关键词终端绿每篇最多 5 处；关键句加粗最多 3 处。
- 品牌名：翊行代码；个人轻量署名：YY；正式署名：王翊仰。

## 禁止项

- 书法、毛笔、飞白、笔墨、水墨晕染、印章、篆刻、宣纸、侘寂、传统纹样。
- 朱红、哑金、咖啡棕、渐变背景、霓虹、赛博朋克、彩色 emoji 装饰。
- 把“一笔”理解成 Logo 造型命令；它只表示一次推进一个动作的方法论。
